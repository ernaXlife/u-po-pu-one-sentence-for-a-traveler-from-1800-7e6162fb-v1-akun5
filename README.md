# One Sentence for a Traveler from 1800 — Entry

One sentence, at most 200 characters, explaining the modern
internet to someone arriving from the year 1800 — built only from
what a person from 1800 already knows.

## How it works

`main.py` writes the sentence to `/output/entry.txt`.
Stdlib only, offline, deterministic.

## The sentence

> Imagine a library the size of the world, where every letter arrives the instant it is written, and anyone may read or answer it.

128 characters, one sentence.
